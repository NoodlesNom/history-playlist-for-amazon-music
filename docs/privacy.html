History Playlist for Amazon Music · Version 1.0.0 · October 2, 2026

This page describes the Microsoft Edge extension "History Playlist for Amazon Music", published by NoodlesNom. The extension is not affiliated with Amazon. The developer collects no data.

What it does

  • It is a content script on the English Amazon Music sites: music.amazon.com, .ca, .co.uk, .com.au, .in, and .ae.
  • The Make playlist button and panel appear only on expanded Song History.
  • It reads song links already shown on that page so it can collect unique track ids from the top of the list. Duplicate ids are skipped.
  • It scrolls that page so more Song History rows can load. Nothing is written to extension storage.
  • When you choose Create playlist, it asks Amazon Music, with the sign-in already in that tab, to create a new public playlist with the name you typed and to add those track ids. That request goes to Amazon (music.amazon and gql.music.amazon), not to the developer.
  • It then loads the new playlist with a full page load.
  • The toolbar icon opens https://music.amazon.com/recently/played/songs. If the current tab is already an English Amazon Music site, it uses that tab. Otherwise it opens a new tab. That click does not read other sites' page contents.

What it does not do

  • It does not send Song History, titles, or track ids to the developer. There is no analytics, no tracker, and no server run by the developer.
  • It does not ask for your Amazon password. It uses the session the Amazon Music page already has.
  • It does not play, pause, or skip.
  • It does not download or display lyrics.
  • It does not change Find in Playlist or Lyrics Translate.

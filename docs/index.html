Make a playlist from Song History

Turn the top of Song History into a new playlist.

History Playlist for Amazon Music is a free Microsoft Edge extension. On the expanded Song History page, a Make playlist button asks for a name and how many songs. It skips duplicates, creates a new playlist, and then loads that playlist with a full page load. The toolbar icon opens Song History.

Playlist from Song History

Create playlist

What it does

Only on the expanded Song History page. It does not change playback.

+

Make playlist

The button is on expanded Song History. It opens a panel for the playlist name and the song count. Leave the count empty to use 25.

#

Name and song count

The name is the title of the new playlist. The count is how many songs to take from the top of Song History.

1

Skips duplicates

The same song is only counted once, even if it shows up again while the list loads.

↓

Loads more rows

Song History only shows part of the list at first. The extension scrolls so later songs can be included.

▶

New playlist, then a full page load

It creates a new public playlist, adds the songs, and opens that playlist with a full page load. It does not edit a playlist you already have.

◎

Toolbar icon

Clicking the toolbar icon opens Song History in the current tab when that tab is already Amazon Music. Otherwise it opens a new tab. The in-page button stays.

Load unpacked (Chrome and other browsers)

  1. Download the ZIP from the latest release and unzip it (or clone the repo).
  2. Open edge://extensions (in Chrome: chrome://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the folder that contains manifest.json.
  5. Open Song History on music.amazon.com. The toolbar icon opens that page.

Where it runs

The Make playlist button appears only on expanded Song History on the English Amazon Music sites: music.amazon.com, .ca, .co.uk, .com.au, .in, and .ae. Other pages do not show the button.

The toolbar icon always opens music.amazon.com/recently/played/songs. If the current tab is already one of those Amazon Music sites, it uses that tab. Otherwise it opens a new tab.

Privacy

No account with us

There is no sign-in to the developer, no analytics, and no server of ours. Removing the extension removes it.

Amazon, only to make the playlist

The playlist name and the song ids already on the Song History page are sent to Amazon Music, using the sign-in already in that tab, to create the playlist and add the songs. Nothing is sent to the developer.

What it does not do

It does not read your Amazon password, sell data, or change Find in Playlist or Lyrics Translate. It does not play, pause, or skip.

Find in Playlist for Amazon Music

On an Amazon Music playlist page, a floating button finds the next song by title or artist, including songs that are not loaded yet. It scrolls that row into view and does not play it. Search stays hidden on the queue, on lyrics, and on the Local Files playlist.
